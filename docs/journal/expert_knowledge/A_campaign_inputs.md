# A. Campaign model inputs: expert knowledge up to the trunk (snapshot 01de54d)

Conventions. C++ files are `agents/AlphaMapAI/<file>`; `.py` files are `campaign_model/<file>` unless prefixed (`bm/` = battle_model/, `gv` = game_values/__init__.py, `priors/` = campaign_model/priors/). Deployed architecture is v2 (`config.py:208` model_architecture="v2"); anything read only by v1 (`model.py` CampaignModel, MapEncoder) counts as unused. "Pre-trunk" = before `think`'s attention blocks (`model_v2.py:971-979`): encode, take_sides, join, see, advise, memory read. Source: E engine raw value, C computed in C++, G computed in graph, T table/CSV/constant, N from NK2, L learned embedding only (combinations like E→L, N→G). amount(x,u) = [log1p(x/s), x/(x+s/4), x/(x+s), x/(x+4s), x>0] with s = UNITS[u] (CI-001/002). soft(x,h) = x/(abs(x)+h).
