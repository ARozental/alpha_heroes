# B. Campaign model: expert knowledge in the decision heads and training targets

Snapshot: `src_dj` (commit 01de54d, deploy 68's line). Scope: model_v2 decision heads, CustomFeatures priors (model.py), features.py helpers that feed logits, views/advice/foresight/nk_predict/labels/credit, the C++ action/legality/NK2 side. Input encoding up to the trunk (encoders.py, Encoder.cpp's state fields, take_sides, U-Net, tile reader) is the other reader's; where a fact also re-enters after the trunk it is listed here with "boundary".

Path prefixes: `mv2`=campaign_model/model_v2.py, `m`=campaign_model/model.py, `ft`=campaign_model/features.py, `vw`=campaign_model/views.py, `pr`=campaign_model/priors.py, `csv/`=campaign_model/priors/, `emp`=campaign_model/empire.py, `lab`=campaign_model/labels.py, `fs`=campaign_model/foresight.py, `nkp`=campaign_model/nk_predict.py, `adv`=campaign_model/advice.py, `tr`=campaign_model/train.py, `lr`=campaign_model/learner.py, `cfg`=campaign_model/config.py, `cst`=campaign_model/constants.py, `gv`=game_values/__init__.py, `play`=campaign_model/play.py; C++ in agents/AlphaMapAI/: `AdvC`=Advice.cpp, `MatC`=Match.cpp, `ActC`=Actions.cpp, `TchC`=Teacher.cpp, `AMC`=AlphaMapAI.cpp, `EncC`=Encoder.cpp, `ArmC`=Armies.cpp, `ArmH`=Armies.h. `vl()` = `ft.value_logit`. "zi" = zero-initialised. "bnd lo..hi (s)" = `ft.bounded` correction, range lo..hi, start s, step x10, AdamW-decayed toward s.

Source codes: E engine raw; C computed in C++ (bends the raw-inputs rule); G computed in graph; T table/CSV/constant; N from NK2; L learned only.

## C. Surprises

1. **Inert in the deployed line**: NK2 candidate prior (CG-155, betas 0), NK2 label prior (CG-156), town guard (CG-157, `left_danger` computed for nothing), teacher CE/span/sets/weights/night-drop (CG-166, CG-203, CG-204), valves (CG-201), alternative credits (CG-202), couplings/`trade_weight`/`trade_unlock` (CG-046, still decayed as corrections), `castable` (CG-013, `INFO_SPELLS` empty), DISMISS head and its -5 bias (CG-015, never legal), fs_turn and nk_predict outputs (CG-179, CG-173: not read). 2. **MOVE vs TRAVEL time pricing**: TRAVEL is discounted 1/(0.75+d^1.3) from the start; MOVE's discount power starts at exactly 0 (CG-068), so a pickup 1 tile away and one 30 tiles away (reached today) price the same. `move_discount` sits outside the corrections (no decay).
3. **Danger in inputs, night in the logit**: the logit prior drops the danger term for the night term, but `tile_value` (all MOVE views) and the network's "value" feature keep danger (CG-069, CG-074); `danger_gain` cannot affect the MOVE logit prior.
4. **Type score adds max(prior) to max(learned)** from possibly different entries (CG-029). BUILD's learned `nk2_build` sits in the "prior" dict and RECRUIT's `recruit_prior` in prior, yet neither enters their type's offer (CG-031, CG-095, CG-098): NK2's build and recruit habits can't raise P(BUILD) or P(RECRUIT).
5. **Suspected bug, RECRUIT "all"**: C++ drops duplicate amounts, so with <=3 affordable the whole purchase sits at index 0 or 2, never 3; the +2 "all" bonus (CG-098) then lands on nothing, while levels with >=4 affordable get it. That tilts the prior toward cheap levels, against its own +0.4/level. `nk2_amount` (CG-130) keys on value and has no such issue.
6. **Inconsistent P(win)**: tile value uses sigmoid(4r) learnable (CG-055); `fight_forecast` uses sigmoid(2r) for the same tile's non-monster fight (CG-181); enemies beat us at sigmoid(2r) fixed (CG-041 etc.).
7. **Behaviour decided in C++** (vs "Python owns the science"): dwelling dialog's creature (CG-021), UPGRADE target (CG-011), TRAVEL target tile (CG-005), market trade route (CG-026), stack merging before every decision (CG-023), GATHER/GIVE_ALL's kept creature, DROP stack sets (CG-019), exchange cap 8 and MULTI ending it (CG-022), 256 decisions a day, auto-closed dialogs (CG-020).
8. **Heuristic masking** (vs "actions are never masked by heuristics"): no-effect and state-loop entries are masked (CG-024).
9. **Values computed in C++ before the network**: travel_days/travel_stop (CG-006), MOVE legality and w_turns/MP left (CG-004, CG-081), `build_short` (CG-007), `x_take_*` NK2 armies (CG-018), `h_drop*` (CG-019), question effect flags from text templates (CG-025), every NK2 field (CG-135..137, CG-152, CG-159).
10. **NK2 fixed point**: `k_score` is priority x100 rounded, so priorities below 0.005 read as "unscored" although they span six orders of magnitude (vw:129-131); `k_danger` is capped at a ratio of 1000 (CG-135).
11. **Exploration scale**: a 2x2-tile TRAVEL area fully hidden is worth the same 600 g as a MOVE step revealing ~120 tiles (CG-086 vs CG-065); Φ pays 5 g/tile.
12. **Stronger-hero mismatch**: GIVE_ALL's cost and meetings use level/multiplier/gold (CG-114, CG-066); NK2's exchange advice ranks MAIN role/evaluateHero first (CG-164). `hero_roles` gives 0 main heroes with 0 towns (CG-040).
13. **Approximations**: TRAVEL base_days = own days x MPmax/1500, counting all of today (CG-146), while MOVE's is exact path MP; Python GATHER counts the whole fitting garrison while C++ keeps one creature (CG-111 vs ActC:348-361).
14. **Unit mixing**: object_values.csv treats NK2 scores as Φ gold for non-immediate objects (CG-049); class values average them (CG-086).
15. **Unbounded / large**: mixer direct weight is a plain parameter (CG-080); DROP prior reaches about -32 logits (CG-116); town_night's last-town stake = whole Φ can dominate a tile prior (CG-071); `vl()` grows as log for large sums.
16. **Doc/code drift**: views FastLinear "52 weights" vs 51+2=53 (mv2:574 vs CG-151); `army_slot_priors` says the within-army -5 "keeps ARMY's type score", but on the learned part it enters `best_legal` and lowers it (m:501-505, CG-107); the v2 draft's single softmax was not built (CG-001).
17. **Hidden knob**: `ALPHA_TOWN_NIGHT` env (default 2) changes the MOVE/TRAVEL priors outside the config (CG-071).
18. **NK2 knowledge outside the switches**: weights descend from NK2 behaviour cloning and ~3,000 updates of teacher CE (CG-167; J13 notes the teacher held 60-65% of the trunk gradient); the advantage head's `adv_named` term, read at gain 1, is a learned bonus for "NK2's choice" (CG-168/169); the plan head carries NK2's plan into games without the advisor (CG-171).
19. **Hidden information in targets** (by design): labels use every player's exact Φ (CG-187); the privileged critic reads rivals' states (CG-186).
